# Lumière Spa & Beauty

Premium responsive React JS website with:
- Home
- About
- Services
- Gallery
- Booking
- Contact
- Responsive navigation
- Booking form demo
- Reusable components
- Premium beige/brown design

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually http://localhost:5173

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Replace the demo images in `src/pages` with your own photos.
- Update address, phone and email in `Footer.jsx`, `Booking.jsx`, and `Contact.jsx`.
- Connect the booking/contact forms to your backend, Formspree, EmailJS, or an API.
- Update colors in `src/index.css` using the CSS variables at the top.
